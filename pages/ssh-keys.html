Security & Authentication

Generate & Test GitHub SSH Keys

Securely connect your local machine to GitHub without typing your password every time.

Why SSH?

Why SSH Keys are Used

  • Problem with HTTPS: Requires a personal access token (or password) every time you push or pull.
  • Benefits of SSH: Uses cryptographic keys for secure, passwordless authentication.
Key Pair

SSH Key Pair

SSH uses two linked keys:

  • Private Key (id_rsa): Stays on your machine. NEVER share this.
  • Public Key (id_rsa.pub): Uploaded safely to GitHub.
Generate Key

Generate SSH Key

Run the following command in your terminal, replacing the email with your GitHub email:

ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

Explanation:

  • ssh-keygen: The key-generation program.
  • -t rsa: Specifies the RSA algorithm.
  • -b 4096: Specifies a strong 4096-bit key size.
  • -C "email": Adds a label (comment) to identify the key.
Passphrase

Optional Passphrase

When prompted, you can enter an optional passphrase for extra security. If someone steals your laptop, they still need the passphrase to use the key.

Add to GitHub

Add Public Key to GitHub

  1. Copy the contents of ~/.ssh/id_rsa.pub
  2. Go to GitHub ➔ Settings
  3. Click SSH and GPG keys
  4. Click New SSH key and paste the contents.
Test Connection

Test Authentication

Verify that your key is correctly set up and recognized by GitHub.

ssh -T git@github.com

Expected Output:

bash — ssh-test
$ ssh -T git@github.com
Hi username! You've successfully authenticated, but GitHub does not provide shell access.
