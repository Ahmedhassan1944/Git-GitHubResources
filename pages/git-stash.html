Temporary Storage

Git Stash

Save your unfinished work without committing. Switch context instantly.

What is Git Stash?

📁

Working Directory

Your active, unfinished code.

git stash
↓
📦

Stash Stack

Safe storage for later.

git stash pop
↑

Real-World Scenario

👨‍💻
Working on Feature A
🚨
Urgent bug reported!
📦
Run git stash — work is saved
🌿
Switch to hotfix branch
🐛
Fix the bug & commit
🔙
Return to feature branch
✅
Run git stash pop — continue Feature A

What Gets Saved?

✅ Default `git stash` saves:

  • ✓ Tracked modified files
  • ✓ Tracked staged files

❌ Default does NOT save:

  • ✗ Untracked new files
  • ✗ Ignored files

✅ With `-u` also saves:

  • ✓ Untracked new files
💡 Always use git stash -u when you have new files you haven't run git add on yet.

Commands Reference

Create

git stash

Save tracked changes and clean working directory

git stash
Create

git stash push -m "msg"

Save with a descriptive name (recommended)

git stash push -m "message"
Create

git stash save "msg"

⚠️ Deprecated syntax — prefer push -m

git stash save "message"
Create

git stash -u

Include untracked new files (or --include-untracked)

git stash -u
Inspect

git stash list

Show all saved stashes

git stash list
Inspect

git stash show

Show changed files in latest stash

git stash show
Inspect

git stash show -p

Show full diff of latest stash

git stash show -p
Restore

git stash apply

Restore changes, keep stash

git stash apply
Restore

git stash apply stash@{2}

Restore a specific stash by index

git stash apply stash@{2}
Restore

git stash apply --index

Restore changes AND original staging state

git stash apply --index
Restore

git stash pop

Restore changes AND delete stash

git stash pop
Restore

git stash pop --index

Restore changes & staging, then delete stash

git stash pop --index
Clean

git stash drop stash@{1}

Delete one specific stash

git stash drop stash@{1}
Clean

git stash clear

Delete ALL stashes permanently (danger)

git stash clear

`apply` vs `pop`

git stash apply

  • ✅ Restores changes to Working Directory
  • ✅ Keeps stash in list
  • 🔁 Can be applied multiple times
  • 💡 Use when: you might need the stash again
VS

git stash pop

  • ✅ Restores changes to Working Directory
  • ❌ Deletes stash after restore
  • ⚡ Most common workflow
  • 💡 Use when: you're done with the stash

Stash Numbering

Git automatically renumbers all stashes after a drop.

stash@{0} — "feat: login UI"
stash@{1} — "fix: navbar colors"
stash@{2} — "wip: dashboard"

⚠️ Common Mistakes

Thinking stash saves untracked files

Use -u flag for new files

Thinking `pop` never causes conflicts

pop is a merge; conflicts can happen

Thinking restored changes always go to staging

They go to Working Directory by default; use --index to restore staging state

Forgetting `pop` deletes the stash

Use apply if you're unsure

Using `clear` by accident

Clears ALL stashes permanently, no undo

Using stash as long-term storage

Create a branch instead

⏱️ Short interruption (minutes/hours)? → Use git stash
📅 Long interruption (days/weeks)? → Create a branch
🤝 Need to share work with teammates? → Create a branch
💾 Need a backup? → Create a branch
