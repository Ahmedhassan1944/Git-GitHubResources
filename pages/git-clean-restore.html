Cleanup & Undo

Clean & Restore

Remove untracked clutter safely, and undo a mistaken git add without losing your work.

📁 Working Directory
→
📋 Staging Area
→
💾 Repository

Git Clean acts on the Working Directory. Git Restore --staged acts on the Staging Area.

What is an untracked file?

📄 app.js ✅ Tracked
📄 style.css ✅ Tracked
📄 notes.txt ⚪ Untracked
📄 temp.log ⚪ Untracked

⚠️ Common Misconception

  • ❌ "git clean deletes everything in the Working Directory" — WRONG
  • ✅ "git clean only removes untracked files — tracked files and their edits are always safe"

Preview vs Delete (Interactive)

app.js Tracked, Modified (always safe)
notes.txt Untracked
temp.log Untracked
Preview

git clean -n

Shows what would be deleted. Deletes nothing. Always run this first.

git clean -n
Delete

git clean -f

Deletes untracked files only. Tracked files are never affected.

git clean -f
Delete

git clean -fd

Also removes untracked directories, not just files.

git clean -fd
Delete

git clean -fx

Also removes files ignored by .gitignore — use with extra care.

git clean -fx

Git Restore --staged

git add ⬆️ Working Directory → Staging Area
git restore --staged ⬇️ Staging Area → Working Directory (undo the add — work is NOT lost)

Comparison

git clean

  • Works on: Untracked files
  • Action: Deletes files
  • Recoverable: ⚠️ Not easily
  • Flags: -n preview, -f force
VS

git restore --staged

  • Works on: Tracked, staged files
  • Action: Removes from Staging Area only
  • Recoverable: ✅ Always — no data lost
  • Flags: none needed, just the filename

⚠️ Common Mistakes

Thinking git clean deletes tracked files

It never touches tracked files, only untracked ones.

Thinking git clean deletes modified tracked files

Modified tracked files are always safe.

Thinking git clean -n deletes anything

-n is preview-only, zero files removed.

Thinking git restore --staged removes your changes

It only unstages; your edits stay in the Working Directory.

Thinking git restore --staged restores the last commit

It does not touch file content at all, only the staging state.

Correct! Nothing is lost. It simply leaves the Staging Area and goes back to being modified in the Working Directory.

Correct! notes.txt deleted (untracked). style.css unstaged to Working Directory as Modified. app.js unchanged throughout.
